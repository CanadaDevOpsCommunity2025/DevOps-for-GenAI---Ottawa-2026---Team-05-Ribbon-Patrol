# GitPet — AI-Powered DevSecOps Companion

Interactive DevSecOps repository companion powered by Google Gemini Live Audio, Vision, and reasoning.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or bun

### Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure environment:
   Create a `.env` file or copy `.env.example` and set your `GEMINI_API_KEY`:
   ```bash
   cp .env.example .env
   # Edit .env with your Gemini API key
   ```
3. Run the app:
   ```bash
   npm run dev
   ```
