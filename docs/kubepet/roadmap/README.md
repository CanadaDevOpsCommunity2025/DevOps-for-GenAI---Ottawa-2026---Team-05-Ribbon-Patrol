# Roadmap

## Delivery roadmap

This roadmap turns the remaining GitPet gaps into implementation-ready work.

### Delivery principles

Every roadmap task must preserve GitPet’s Notice → Understand → Resolve loop.

* Repository facts come from structured snapshots only.
* Every write remains previewed, reversible, and developer-approved.
* Sandbox mode remains deterministic for the demo.
* Live Workspace Mode remains opt-in and read-only.
* AI, voice, and image failures always retain a usable fallback.

### Completion standard

A task is complete only when its acceptance criteria pass. It must also pass lint and build checks. New controls need keyboard access and clear empty, loading, and error states.

The final rehearsal validates all scenarios and integration boundaries. It is the delivery gate for this roadmap.
