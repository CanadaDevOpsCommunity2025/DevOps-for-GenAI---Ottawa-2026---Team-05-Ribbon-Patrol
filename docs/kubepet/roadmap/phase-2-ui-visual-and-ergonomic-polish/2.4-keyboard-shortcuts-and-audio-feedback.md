# 2.4 Keyboard shortcuts and audio feedback

## Objective

Improve rapid navigation without disrupting typing, assistive tools, or quiet environments.

### Scope

Update `src/App.tsx`, `src/components/TopBar.tsx`, and `src/components/PetStage.tsx` as needed.

### Keyboard requirements

* `Cmd+K` or `Ctrl+K` opens the Quick Palette.
* `Cmd+B` or `Ctrl+B` toggles the Repository Drawer.
* `Esc` closes the active modal, palette, or drawer.
* `Space` pets the mascot only when focus is not in an editable control.

The Quick Palette includes searchable actions for scenarios, the drawer, demo start, and core modals. Display shortcut hints where useful.

### Audio requirements

Provide optional, subtle effects:

* Chime after verified synchronization.
* Alert when a conflict or unsafe state appears.
* Short pet interaction sound.

Audio is disabled by default or respects the existing sound preference. Never autoplay before a user interaction. Include an accessible mute control.

### Shortcut routing

Register shortcuts once at the application shell. Ignore modifier conflicts with browser-reserved behavior where required. Do not intercept keys from inputs, textareas, content-editable elements, or active composition events.

The Quick Palette opens with focus in its search field. It lists each action’s shortcut and supports arrow navigation, selection, and Escape. It must not expose destructive actions without the existing confirmation gate.

Layered UI follows a strict close order: confirmation modal, other modal, Quick Palette, then drawer. Escape never discards unsaved prompt text without a clear existing discard behavior.

### Sound behavior

Load audio only after the developer enables sound or first interacts with a sound control. Rate-limit repeated effects during rapid state updates. The enabled preference persists for the current browser context.

Each effect has a non-audio equivalent: visual sync confirmation, state alert, or pet animation. Audio failure is silent and non-blocking.

### Acceptance criteria

1. Shortcuts work on macOS and non-macOS platforms.
2. Shortcuts do not trigger while typing in editable fields.
3. `Esc` closes only the topmost active surface.
4. Sound effects are optional and never block UI actions.
5. Petting works through mouse and keyboard interactions.
6. Quick Palette actions work with pointer and keyboard selection.
7. Audio failures never alter repository state or block interaction.

### Verification

Test each shortcut with focus in chat and inputs. Test audio enabled and muted after a user gesture.
